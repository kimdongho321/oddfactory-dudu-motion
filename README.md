# 두두 키우기

[최신 APK](https://github.com/kimdongho321/oddfactory-dudu-motion/releases/latest)를 설치하고 앱에서 실행을 눌러요. 처음 실행할 때 ‘다른 앱 위에 표시’를 허용해 주세요. 알을 세 번 톡톡 두드리면 두두가 깨어나요.

Android 소스를 빌드하려면 JDK 17, Android SDK 35, Python 3.10 이상과 Pillow가 필요합니다. `android` 폴더에서 Windows는 `gradlew.bat assembleDebug`, macOS·Linux는 `./gradlew assembleDebug`를 실행하세요.

트릭컬 리바이브 비공식 팬 프로젝트입니다. 메이플스토리 글꼴의 고지는 `android/runtime/fonts/Maplestory-LICENSE.txt`에 있습니다.
