# 두두 도트 모션

두두의 일반·야광 도트 모션 10개를 재생하는 개발 중인 웹 뷰어입니다. 모션 버튼으로 재생할 동작을 선택하고, 일반·야광 전환과 일시정지, 프레임 이동, 확대를 사용할 수 있습니다.

## 로컬 실행

Python 3이 있는 환경에서 이 폴더를 열고 다음 명령을 실행합니다.

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory web
```

브라우저에서 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)을 엽니다. Windows에서는 8852 포트가 비어 있을 때 `serve.bat`으로 실행해 [http://127.0.0.1:8852/](http://127.0.0.1:8852/)을 열 수도 있습니다.

`web/index.html`에 화면과 재생 코드가 있고, `web/motions.json`에 모션별 재생 순서와 시간이 들어 있습니다. `web/frames/`의 일반·야광 PNG를 그대로 사용하므로 별도 빌드나 패키지 설치 없이 실행할 수 있습니다.

## 개발 상태

버튼 아래의 휴대폰 이벤트는 Android 연동 계획입니다. Android 앱 구현, APK 빌드, 실기기 검증은 후속 단계입니다. 이 스냅샷에는 웹 뷰어와 뷰어에서 쓰는 도트 모션만 담았습니다.

트릭컬 리바이브의 두두를 바탕으로 만든 비공식 팬 프로젝트입니다. 캐릭터와 게임 IP는 에피드게임즈에 있습니다.
